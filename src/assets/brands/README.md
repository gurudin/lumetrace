# Feedback channel brand assets

These marks identify the external feedback destinations, not Lume Trace features or endorsements.
Assets are bundled locally; opening the dialog never fetches logos from a third party.

- `github-mark.svg`: GitHub's official Primer Octicons `mark-github-24.svg`.
  Source: https://github.com/primer/octicons/blob/main/icons/mark-github-24.svg
  License: MIT (reproduced below). GitHub's trademarks remain GitHub's property.
- `discord-mark.svg`: official Clyde symbol, copied without changing its vector geometry.
  Brand guidelines: https://discord.com/branding
  Source: https://cdn.prod.website-files.com/6257adef93867e50d84d30e2/66e3d80db9971f10a9757c99_Symbol.svg
  Discord's logo and trademarks remain Discord's property; they are not covered by the MIT license below.

Light appearance uses the black GitHub mark and Discord Blurple (#5865F2).
Dark appearance renders the same silhouettes in white. Preserve aspect ratios and clear space.
