# LumeTrace v1.0.3

**Find the exact passage you need, then open it in context.**

This release improves content search, version-safe recovery, and everyday file handling in local workspaces.

## What's in v1.0.3

- **Search inside files.** Search results can show the matching passage instead of only the file name.
- **Open at the match.** Markdown, text, and PDF results open at the relevant content with the query highlighted.
- **Clearer search states.** The compact Command-K layout remains unchanged until content matches need more room.
- **Safer backup recovery.** Restored backups open as a separate workspace instead of overwriting the active workspace.
- **Better file renaming.** The file extension is no longer selected by default when renaming a file.
- **Natural AI source counts.** AI answers now use the correct singular or plural label for referenced files.

## Download

### macOS — Apple Silicon

Download `LumeTrace_1.0.3_aarch64.dmg` from **Assets** below.

LumeTrace v1.0.3 supports Apple Silicon Macs.

## Installation

This build is **not Developer ID signed or notarized by Apple**, so macOS may block it from opening normally.

After copying LumeTrace to Applications, try to open it once. If macOS blocks it, open System Settings → Privacy & Security and use **Open Anyway** for LumeTrace. Do not disable Gatekeeper globally.

## Known limitations

- Windows and Linux installers are not available in v1.0.3.
- Team collaboration and cloud/NAS synchronization are not included in this Community release.
- OCR is not included.
- Claude Code and OpenCode integrations remain experimental.
- AI features are optional. When using an external AI provider, relevant content may be sent to the selected provider as part of a user-initiated request.

Your physical files and workspace storage remain local.
