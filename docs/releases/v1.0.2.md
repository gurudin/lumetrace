# LumeTrace v1.0.2

**A more reliable local-first workspace for your files.**

This maintenance release improves everyday file handling, version recovery feedback, and local semantic indexing stability.

## What's in v1.0.2

- **Reliable file opening and editing.** Double-click files, choose another application, and continue editing through your usual macOS applications.
- **Stable file browsing.** Renamed files remain visible in the current workspace instead of disappearing from the active view.
- **Clear version recovery feedback.** Restoring an earlier version now shows progress and prevents repeated restore requests while work is in progress.
- **More robust semantic indexing.** SQLite index writes are coordinated to reduce conflicts while local indexing runs in the background.

## Download

### macOS — Apple Silicon

Download `LumeTrace_1.0.2_aarch64.dmg` from **Assets** below.

LumeTrace v1.0.2 supports Apple Silicon Macs.

## Installation

This build uses an Apple Development certificate. It is **not Developer ID signed or notarized by Apple**, so macOS may block it from opening normally.

After copying LumeTrace to Applications, try to open it once. If macOS blocks it, open System Settings → Privacy & Security and use **Open Anyway** for LumeTrace. Do not disable Gatekeeper globally.

## Known limitations

- Windows and Linux installers are not available in v1.0.2.
- Team collaboration and cloud/NAS synchronization are not included in this Community release.
- OCR is not included.
- Claude Code and OpenCode integrations remain experimental.
- AI features are optional. When using an external AI provider, relevant content may be sent to the selected provider as part of a user-initiated request.

Your physical files and workspace storage remain local.
