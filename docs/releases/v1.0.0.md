# Lume Trace v1.0.0 — Feature freeze

- Status: user-accepted feature freeze, confirmed on 2026-09-05.
- Scope: free, single-user macOS desktop application.
- Product focus: every file has a timeline; recorded versions, text Diff, and version recovery are the core capabilities. AI remains optional.
- Accepted feature baseline: `7085af3` on `develop`.
- Freeze preparation changes only application version metadata, lockfiles, documentation, and version-consistency regression coverage. No business behavior, dependencies, storage identifiers, or database schema are changed.

## Frozen scope

The implemented capabilities and limitations remain those documented in the [README](../../README.md): file workspaces and isolation, version timeline and text Diff, preview and recovery, full-text and local semantic search, Trash and backup, background status, and optional source-grounded AI queries.

The final feedback entry includes GitHub Issues and the Lume Trace Discord community, using bundled official brand marks. The configured Discord invite was checked through Discord's public API with `expires_at: null`.

Claude Code and OpenCode remain explicitly **experimental**. Windows/Linux release acceptance, team collaboration, synchronization, OCR, and application-specific migrations are not part of this accepted scope.

## Change control

Do not add features or perform unrelated refactoring as part of v1.0.0 freeze preparation. Any later fix must be scoped, verified, and explicitly tracked; additional features belong to a subsequent version agreed with the user.

Keep working and committing on `develop` under the existing repository rules. This freeze does not authorize switching or merging to `main`, creating release tags, publishing a GitHub Release, or distributing an installer.
