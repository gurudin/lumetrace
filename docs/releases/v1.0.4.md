# LumeTrace v1.0.4

**Search the words and objects inside your visual files, then open them in context.**

This release expands local search and file opening for everyday workflows.

## What's in v1.0.4

- **Search text inside images and scanned PDF pages.** macOS Apple Vision performs on-device OCR and keeps the extracted text in the local search index.
- **Search images by visible subjects.** Image categories are indexed locally, so searches such as “cake” can find matching images without uploading them or downloading a recognition model.
- **See the match in context.** Image and PDF search results show the original visual with the matching text region highlighted.
- **Open files with the default system app.** Use the file action to open a document in its normal macOS application.

## Download

### macOS — Apple Silicon

Download `LumeTrace_1.0.4_aarch64.dmg` from **Assets** below.

LumeTrace v1.0.4 supports Apple Silicon Macs.

## Installation

This build is **not Developer ID signed or notarized by Apple**, so macOS may block it from opening normally.

After copying LumeTrace to Applications, try to open it once. If macOS blocks it, open System Settings → Privacy & Security and use **Open Anyway** for LumeTrace. Do not disable Gatekeeper globally.

## Scope

Team collaboration and cloud/NAS synchronization are not included in this Community release. AI services remain optional; local file browsing, version history, Diff, full-text search and local image recognition do not require an AI service.

LumeTrace is free and open source.
