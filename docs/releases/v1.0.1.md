# LumeTrace v1.0.1

**A local-first workspace for your files.**

Organize your local files, search what's inside, ask questions with AI, and keep every version as your files change.

## What's in v1.0.1

- **Help when you need it.** Open the new Help Center from the bottom-right question mark. Search offline guides for file operations, AI setup, local semantic indexing, backups, and more. Full articles are available in Simplified Chinese and English.
- **More useful version history.** Open recent versions from a file's version badge, add notes, and mark important versions as milestones. Expand the full timeline when you need to compare or restore earlier work.
- **Cleaner previews.** Version history starts collapsed, with version counts available when you need them. The timeline header stays visible while you browse longer histories and file content.
- **Smoother image browsing.** Improved thumbnail reuse and loading feedback reduce repeated loading while scrolling. Request the original image on demand when a processed preview is not enough.
- **Clearer feedback.** File-operation messages remain visible above dialogs, and recovered workspaces no longer keep showing stale loading errors.

## Known limitations

- Windows and Linux installers are not available in v1.0.1.
- Team collaboration and cloud/NAS synchronization are not included in this Community release.
- OCR is not included.
- Claude Code and OpenCode integrations remain experimental.
- AI features are optional. When using an external AI provider, relevant content may be sent to the selected provider as part of a user-initiated request.

Your physical files and workspace storage remain local.
