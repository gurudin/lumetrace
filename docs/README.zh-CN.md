# Lume Trace

**一款本地优先的文件空间，提供自动版本历史、全文与语义搜索，以及带来源引用的 AI 问答。**

[English](../README.md) · [开发说明](DEVELOPMENT.md) · [导入与迁移边界](MIGRATION.md)

Lume Trace 面向个人与小团队的文件工作流。实体文件仍保存在用户选择的文件夹中，Lume Trace 在本地维护文件信息、历史版本、搜索索引、废纸篓和 AI 对话记录，让文件始终可管理、可检索、可恢复、可溯源。

## 当前已经实现

### 本地优先的文件空间

- 可以新建空文件空间，也可以从已有实体文件夹初始化。
- 可以创建多个自定义名称的文件空间并进行切换。
- 每个文件空间独立保存数据库、版本快照、搜索索引、废纸篓和 AI 对话历史。
- 删除文件空间时，实体文件夹不会被删除；用户可以分别决定仅移除文件空间记录，还是同时删除 Lume Trace 管理的数据库与版本数据。
- 支持导出备份，并在所选目录创建新的实体根目录后恢复到当前文件空间；恢复不会删除原来的实体文件夹。

### 可溯源的文件版本

- 导入已有文件时为每个文件建立初始版本。
- 监听第三方应用对实体文件的修改，并在后台自动生成新版本。
- 外部修改生成版本后进行通知，可直接查看该文件的版本时间线。
- 支持查看历史版本、预览历史内容、切换当前版本，以及对文本版本进行逐行和词级 Diff。
- 同一文件夹导入同名文件时，明确选择“合并为最新版本”或“重命名为独立文件”；内容完全相同时跳过导入并可直接定位原文件。

### 搜索与本地知识索引

- macOS 使用 `Command + K`，Windows 和 Linux 使用 `Alt + K` 唤起全局搜索。
- 使用 SQLite FTS5 搜索文件名、异步提取的正文与 Tag。
- 可以安装内置的多语言 Embedding 模型进行本地语义排序，向量和索引都保留在设备上。
- 文件导入完成后再异步提取正文和建立索引，不让导入流程等待 AI 或索引处理。
- 支持提取 PDF、DOCX、XLSX、PPTX、Markdown、TXT、源代码和常见结构化文本的正文。
- 可以查看、暂停、恢复和重试正文提取及语义索引后台任务。

### Lumie · AI 文件助手

- 可以围绕当前整个文件空间提问，而不是只查找单个文件。
- 先在本地检索有限数量的相关正文片段，仅将命中的片段发送给当前选中的 AI 服务，并在回答下方展示参考文件。
- 回答会保留对应的文件和版本引用。
- 每个文件空间独立保存对话历史；连续追问会注入最近上下文，重启应用后历史和追问上下文仍然保留。
- 当前可通过 Ollama、LM Studio 等 OpenAI Compatible 本地模型服务执行问答，也可使用文件权限为“只读访问”的 Hermes Agent CLI。

### 文件管理与恢复

- 提供自适应网格与列表布局；大文件空间使用分页查询和视口虚拟化，避免全量返回与全量渲染。
- 支持创建 Markdown、TXT 文件，以及重命名、移动、多选、拖入文件夹、拖到其他应用、Tag、预览和使用系统应用打开。
- 内置图片、PDF、Markdown 和文本预览。
- 删除内容进入废纸篓；恢复到原位置和手动清空废纸篓都需要二次确认。
- 废纸篓内容在删除 30 天后自动永久清理。

### 桌面体验

- 支持浅色、深色和跟随系统主题。
- 支持简体中文、繁体中文、英文、日文、韩文、德文、法文和西班牙文八种界面语言。
- 使用 Tauri 2 构建，并以当前 macOS 桌面交互为主要视觉与操作基准。

## 当前边界

以下内容目前**尚未实现为可用能力**：

- 团队账号、成员权限、实时协作、NAS 同步与云同步；
- AI 文件助手直接调用云端 OpenAI Compatible API；
- 通过 Claude Code、Codex CLI 或 OpenCode 执行文件空间问答；目前可以检测这些 CLI 的安装和配置状态，但实际问答只接通本地模型与 Hermes；
- 从 Eagle 或其他软件私有数据库一键迁移；
- 对纯图片文档进行 OCR。

## 数据处理流程

1. Lume Trace 先登记实体文件，并让界面结束本次文件操作。
2. 后台任务异步提取可读取的正文并更新本地 FTS5 索引。
3. 安装语义模型后，后台任务继续在本地生成 Embedding。
4. 搜索从索引中获取有限候选结果，不在界面中加载或扫描全部文件。
5. AI 提问先从当前文件空间检索相关片段，再调用当前选中的本地模型或 Hermes，最后在本地保存回答与来源。

## 开发启动

需要 Node.js、npm、Rust 工具链和 Tauri 2 对应的平台依赖。测试 AI 问答链路时，可配置 Ollama、LM Studio 等 OpenAI Compatible 本地模型服务，或安装并配置 Hermes Agent CLI。

```bash
npm install
npm run tauri:dev
```

开发阶段只使用 `npm run tauri:dev`，不要将开发构建安装到 `/Applications`。

常用检查：

```bash
npm test
npm run typecheck
npm run build
cd src-tauri && cargo test --lib && cargo check && cargo fmt --check
```

模块边界、后台任务和验证方法参见 [DEVELOPMENT.md](DEVELOPMENT.md)。
